# Los cuatro padrones

Historia de las cuatro familias de Pablo Ignacio de los Campos Nin: de los Campos y Soma, Acosta y Britos, Nin y Sacarello, Márquez y Fernández.

Para leerla: https://pdelosca.github.io/los-cuatro-padrones/

Es un libro para la familia. La página está marcada para que los buscadores no la indexen. Las fuentes de cada dato están citadas en el texto.
